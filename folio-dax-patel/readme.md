# dax-3d

Interactive 3D portfolio for **Dax Patel** — drive around an open world built with Three.js (WebGPU), Rapier physics, and Vite.

## Run

```bash
npm install --force
cp .env.example .env
npm run dev
```

## Stack

- Three.js WebGPU + TSL
- Rapier physics
- Howler.js audio
- GSAP
- Vite
